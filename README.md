# Bus/Train Ticket Booking Data Analysis Using Python

This BCA final-year project analyzes a reproducible **synthetic** dataset of Indian bus and train bookings. It demonstrates data validation, cleaning, passenger and route summaries, booking/revenue trends, charts, CSV exports, an educational notebook, automated tests, and an editable thesis report. It is not a booking website and contains no real operator or passenger information.

## Objectives and Features

- Analyze passenger ages, gender labels, origin/destination, transport mode, ticket prices, booking status, and monthly patterns.
- Distinguish unique booking count from ticket quantity. Booking revenue is `Ticket_Price * Number_of_Tickets`.
- Recognize revenue only for `Completed` and `Confirmed` bookings. `Cancelled` and `Pending` contribute zero. Refund accounting is outside scope.
- Demonstrate missing-value imputation and exact duplicate removal. Repeated journeys with different booking IDs are valid records and are retained.
- Export cleaned rows, route/destination/month/mode summaries, ten Matplotlib charts, and a plain-text execution summary.
- Generate at least 1,000 reproducible records using seed `20261019` (default raw file: 1,208 rows: 1,200 bookings plus eight exact duplicate examples).

## Technology

Python 3.9 or later, pandas, NumPy (<2 for broad compatibility), Matplotlib, Jupyter, `unittest`, and `python-docx` for the DOCX report.

## Requirements and Setup

Install Python 3.9+ and ensure `python` is available. From this project directory:

```powershell
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Linux/macOS:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

If PowerShell blocks activation, run `.venv\Scripts\python.exe` directly for the commands below. NumPy 2 is excluded because older compiled Matplotlib releases may not be compatible with it.

## Run the Project

From the project root (the directory containing `src`):

```text
python -m src.generate_dataset
python -m src.main
python -m unittest discover -s tests -v
jupyter notebook notebooks/Bus_Train_Ticket_Booking_Analysis.ipynb
python -m src.create_report
```

The main runner also creates the default dataset when it is absent. Use `python -m src.main --regenerate` to recreate it with the default seed, `--data path/to/file.csv` for another compatible CSV, or `--skip-charts` to skip PNG creation.

## Outputs

- Raw synthetic input: `data/raw/booking_data.csv`
- Cleaned records: `data/processed/cleaned_booking_data.csv`
- Grouped summaries: `data/output/`
- Charts: `figures/`
- Cleaning and analysis metrics: `outputs/execution_summary.txt`
- Thesis: `report/BCA_Final_Year_Project_Report.docx`
- Optional rendered report: `report/BCA_Final_Year_Project_Report.pdf` (when Microsoft Word or LibreOffice is installed)

Chart and report numbers are calculated from the CSV generated by the code. Synthetic patterns are demonstrations only and must not be generalized to actual Indian travel demand.

## Troubleshooting

- `ModuleNotFoundError`: activate the project virtual environment and run `python -m pip install -r requirements.txt`.
- `Dataset is missing required columns`: supply a CSV using the exact column names listed in `documentation/data_dictionary.md`.
- `No module named src`: run commands from the project root, not from `src` or `notebooks`.
- Matplotlib import error mentioning NumPy: reinstall requirements in the same interpreter that runs the project; keep NumPy below 2 for older Matplotlib builds.
- DOCX generation requires `python-docx` from requirements. PDF conversion depends on a locally installed Microsoft Word or LibreOffice; no converter is bundled.
