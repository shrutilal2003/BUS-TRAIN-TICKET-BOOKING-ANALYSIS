# Report Sources and Result Provenance

## Dataset and execution

The report's results come from `data/raw/booking_data.csv`, generated by `src/generate_dataset.py` with NumPy seed `20261019`. The raw file is synthetic: 1,200 generated transactions plus eight appended exact duplicate rows. `src/data_cleaning.py` removes the exact duplicates and creates 1,200 cleaned records. No external passenger/operator dataset, survey, institutional record, or real booking system was used.

The DOCX is built by `python -m src.create_report`. That command reruns `src.main`, executes the unittest suite, and embeds current metrics, summary tables, actual PNG figures, and test output. At the report-generation run, results were 1,200 unique bookings, 3,531 tickets, INR 3,880,660.86 recognized revenue, and Varanasi as the most popular destination. Recognized revenue includes `Completed` and `Confirmed`, not `Cancelled` or `Pending`; refunds are not modeled. Rerun the project and report builder together if changing source logic or data.
